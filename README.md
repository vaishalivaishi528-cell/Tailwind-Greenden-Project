# Tailwind-Greenden Project
 GreenDen – Plant Shopping Website

GreenDen is a modern and responsive plant shopping website designed to bring nature closer to everyone. It provides an attractive platform to explore different varieties of plants through a clean and user-friendly interface.

 Key Features:

- Attractive and modern UI design.
- Beautiful plant collections and product displays.
- Clean navigation and organized layouts.
- Responsive website design.
- Visually appealing sections and styling.

 Technologies Used:

- HTML5 – For website structure.
- Tailwind CSS – For styling, layouts, and responsive design.

 Project Objective:
